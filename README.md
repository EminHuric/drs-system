# RDS — Restaurant Digital Solutions

Sav kod je u podfolderu **[`drs-system/`](drs-system/)**.

```bash
cd drs-system
npm run dev          # → http://localhost:5173
```

| | |
|---|---|
| Uputstvo za podešavanje | [drs-system/README.md](drs-system/README.md) |
| Provera Firebase-a | `cd drs-system && node proveri-firebase.mjs` |
| Admin panel | `http://localhost:5173/login` |

Stara aplikacija za jedan restoran (bez prijave i admin panela) je uklonjena.
Rezervna kopija: `Desktop\rds-stara-aplikacija-backup.zip` — slobodno je obriši
kad ti više ne treba.
